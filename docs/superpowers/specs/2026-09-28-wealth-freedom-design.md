# 财富自由公式计算器 — 设计文档

日期：2026-09-28

## 1. 目标

在 `f:\caifu` 下用一个单文件、零第三方依赖的 Python CLI 工具，回答四个问题：

1. 反推财富自由目标金额（FIRE Number）
2. 正推达成财富自由所需年限
3. 反推达成目标所需的每月储蓄额
4. 多情景对比（不同收益率下的结果差异）

## 2. 口径约定

全部金额以**今天的购买力**（实际口径）展示。用户输入名义参数，程序内部折算。

```text
实际年收益率 r    = (1 + 名义收益率) / (1 + 通胀率) − 1
月利率        r_m = (1 + r)^(1/12) − 1
自由门槛      T   = 年支出 ÷ 提取率            # 默认提取率 4% → 25 倍
积累期终值    FV  = P·(1+r_m)^N + PMT·((1+r_m)^N − 1)/r_m
```

- `P` = 现有可投资资产
- `PMT` = 每月储蓄
- `N` = 积累月数
- 按月复利、月末定投（普通年金）

闭式反解：

```text
需多少月   N   = ln((T·r_m + PMT) / (P·r_m + PMT)) / ln(1+r_m)
每月需存   PMT = (T − P·(1+r_m)^N) · r_m / ((1+r_m)^N − 1)
```

## 3. 实现方案

选定**方案 C：解析解 + 迭代校验**。

- 核心结论（年限、所需储蓄）使用闭式公式计算精确值
- 同时用逐月迭代 `资产 = 资产·(1+r_m) + PMT` 生成逐年明细表
- 两种算法结果必须吻合，否则抛出断言错误

理由：既有解析公式的精确与透明，又有逐年明细可直接核对，且公式一旦写错会立即暴露。

## 4. 文件与分层

单一文件 `f:\caifu\wealth_freedom.py`，约 200 行，四层分离，计算层为纯函数无 I/O：

| 层 | 内容 |
|---|---|
| 参数层 | `parse_args()` — argparse，全部参数带默认值 |
| 计算层 | `real_rate()`, `monthly_rate()`, `fire_target()`, `months_to_target()`, `required_monthly_saving()`, `simulate()` |
| 展示层 | `format_report()`, `format_table()` — 只排版，不做计算 |
| 入口 | `main()` — 编排与一致性断言 |

## 6. 输出格式

```text
=== 口径 ===
名义 8.0%  通胀 3.0%  →  实际收益率 4.854%
年支出 6.0万 × (1/4.0%) = 25.0 倍  →  自由门槛 150.0万（今天购买力）

=== 答案 ===
① 现有 20.0万、月存 5000  →  还需 12.4 年，2038-02 达标
② 目标 10 年后自由      →  每月至少需存 7,182 元
③ 当前是否已达标        →  否

=== 逐年明细 ===
 年份    年末资产(万)   当年储蓄(万)   当年收益(万)
 2026       24.1           6.0           1.19
 ...

=== 情景对比 ===
 名义收益率   实际收益率   达标年限   达标年份
    6.0%        2.9%       16.8      2042-07
```

明细表与情景对比表分别在 `--no-table`、未指定 `--scenario` 时不输出。

## 7. 边界与错误处理

| 情形 | 处理 |
|---|---|
| `名义收益率 ≤ 通胀率`（实际收益率 ≤ 0） | 闭式解 `ln(1+r_m)` 会除零或产生负数 → 明确报错"购买力不增长，永远无法达标"，并给出纯储蓄所需年限作为参照 |
| `r_m == 0` | 退化为 `N = (T − P) / PMT` |
| `P ≥ T` | 返回 0 年，标记"已达标" |
| `储蓄 == 0` 且 `P < T` | 报错：无储蓄则永远无法达标 |
| 负数或非法参数 | argparse 阶段拦截 |

## 8. 一致性校验

`main()` 中执行：

1. 闭式解出的 `N` 代回正推公式，终值须落在 `T` 的 `1e-6` 相对误差内
2. 闭式解的 `N` 与 `simulate()` 迭代结果比对，不一致直接抛断言错误

## 9. 测试

`--selftest` 内置三个用例，不引入 pytest，保持单文件零依赖：

1. `r = 0` 退化工况：无收益时 `N = (T − P) / PMT`
2. 已知答案的定投题：手算结果与实现结果一致
3. 解析解与迭代解一致性：同一组参数下两者吻合
