# 财富自由公式计算器 — 设计文档

日期：2026-09-28
版本：第 2 版（取代第 1 版的纯 CLI 方案）

## 1. 目标

在 `f:\caifu` 下做一个**双击即可运行**的个人财富自由推演小工具：命令行 + 可视化。回答七个问题：

1. 财富自由目标资产（FIRE Number）
2. 当前储蓄率
3. 预计达到财富自由的年龄
4. 不同收益率下的达成时间
5. 敏感度分析（各参数扰动对达成年龄的影响）
6. 退休后资产能否撑到预期寿命
7. 输出表格、折线图、结论摘要

## 2. 口径约定

沿用第 1 版：所有金额以**今天的购买力**（实际口径）展示，用户输入名义参数，程序内部折算。

```text
实际年收益率 r    = (1 + 名义收益率) / (1 + 通胀率) − 1
月利率        r_m = (1 + r)^(1/12) − 1
自由门槛      T   = 年支出 ÷ 安全提取率
年储蓄            = 年收入 − 年支出          # 派生，不作为独立输入
储蓄率            = 年储蓄 ÷ 年收入
```

**积累期**（按月复利、月末储蓄）：

```text
FV = P·(1+r_m)^N + PMT·((1+r_m)^N − 1)/r_m
月数 N   = ln((T·r_m + PMT) / (P·r_m + PMT)) / ln(1+r_m)
月储蓄 PMT = (T − P·(1+r_m)^N) · r_m / ((1+r_m)^N − 1)
```

**消耗期**（按月复利、按年支取）：

```text
A_{t+1} = A_t·(1 + r) − 年支出
```

退休后年支出与在职期年支出**同额**（今天的购买力）。消耗期资产继续按实际收益率增值。

## 3. 输入层

**双击运行（无命令行参数）→ 逐项问答；带参数运行 → 命令行直通。** 两条路径共享同一套计算层。

问答顺序与默认值：

| 项 | 类型 | 默认 |
|---|---|---|
| 当前年龄 | 整数，必填 | 无 |
| 当前资产（万元） | 浮点，必填 | 无 |
| 年收入（万元） | 浮点，必填 | 无 |
| 年支出（万元） | 浮点，必填 | 无 |
| 名义年化收益率（%） | 浮点 | 8 |
| 通胀率（%） | 浮点 | 3 |
| 安全提取率（%） | 浮点 | 4 |
| 预期寿命（岁） | 整数 | 85 |

有默认值的项直接回车即采用默认值。每项输入即时校验，非法输入重新提问。

命令行参数沿用第 1 版命名（`--annual-expense`、`--assets`、`--monthly-save`、`--return`、`--inflation`、`--withdrawal`、`--years`、`--scenario`），并新增：

| 参数 | 含义 |
|---|---|
| `--age` | 当前年龄 |
| `--annual-income` | 年收入（万元） |
| `--life-expectancy` | 预期寿命（岁） |
| `--no-chart` | 不生成折线图（无图形环境时使用） |
| `--no-pause` | 双击启动时也不等待回车 |
| `--selftest` | 运行内置校验用例后退出 |

命令行路径下，年储蓄由 `--annual-income − --annual-expense` 派生；若只给 `--monthly-save` 则按年储蓄 = 月储蓄 × 12 处理（此时年收入未知，口径摘要不显示储蓄率）。`--years` 无默认值，显式给出时才在结论末尾追加一条「反推所需储蓄」。

## 4. 计算层（纯函数，无 I/O）

沿用第 1 版并全部保留：`real_rate`、`monthly_rate`、`fire_target`、`months_to_target`、`required_monthly_saving`、`simulate_months`、`cross_check`。

新增：

| 函数 | 职责 |
|---|---|
| `saving_rate(annual_income, annual_expense)` | 储蓄率 = 年储蓄 ÷ 年收入 |
| `build_lifeline(ctx)` | 统一推演一生，见下 |
| `depletion_age(rows)` | 资产首次转负的年龄，未耗尽返回 `None` |
| `rate_scenarios(ctx, rates)` | 不同收益率下的达成年龄 |
| `sensitivity(ctx)` | 参数扰动对达成年龄的影响 |

`simulate_years` 被 `build_lifeline` 取代，改为**按整数年龄逐年推进**，消除第 1 版按自然年对齐时首行只统计部分月份的问题：

- 年龄从 `当前年龄 + 1` 递增到 `预期寿命`，每年一行，返回 `(年龄, 年末资产, 当年储蓄, 当年支取, 当年收益, 阶段)`
- 未退休 → 积累期（按月复利、按月储蓄）；首次跨越门槛的那一年标为「达成」，**退休期自下一年开始**
- **退休一旦开始不可逆**：退休期内即使资产回落到门槛以下，仍继续按年支取（否则会永远算不出耗尽）
- 当前资产已 ≥ 门槛时，退休期直接从第一行开始推演
- 结论中的精确达成年龄仍取闭式解的小数值（保留 1 位小数），与逐年表互补

### 4.1 情景与敏感度的口径

`rate_scenarios` 与 `sensitivity` 都只重算**积累期**的达成年龄，不进入消耗期推演。

## 5. 敏感度分析

以基准情形为中心，对每个参数做单侧扰动，输出达成年龄的变化：

| 参数 | 扰动 |
|---|---|
| 名义收益率 | ±1.0 个百分点 |
| 年储蓄 | ±10%，通过调节**年收入**实现，年支出保持不变（门槛 T 不变，只反映积累速度的影响） |
| 通胀率 | +1.0 个百分点 |

输出表格式：

```text
 参数          变化       达成年龄    相对基准
 基准            —         40.2 岁       —
 名义收益率    +1.0%      39.7 岁      −0.5 年
 名义收益率    −1.0%      40.8 岁      +0.6 年
 年储蓄        +10%       39.5 岁      −0.7 年
 年储蓄        −10%       41.0 岁      +0.8 年
 通胀率        +1.0%      40.8 岁      +0.6 年
```

某行若在该扰动下无法达标，达成年龄列显示「无法达标」。

## 6. 输出层

### 6.1 口径摘要

```text
=== 口径 ===
年龄 30 岁  预期寿命 85 岁
名义 8.0%  通胀 3.0%  →  实际收益率 4.854%
年收入 15.0万  年支出 6.0万  →  年储蓄 9.0万  储蓄率 60.0%
年支出 6.0万 × (1/4.0%) = 25.0 倍  →  自由门槛 150.0万（今天购买力）
```

### 6.2 结论摘要

```text
=== 结论 ===
• 按实际收益率 4.854% 推算，预计 40.2 岁达成财富自由
• 距离预期寿命 85 岁还有 44.8 年，退休后每年支取 6.0 万
• 推演到 85 岁资产仍有 443.8 万，不会耗尽
• 若年储蓄比预期低 10%，达成时间推迟 0.8 年
```

最后一条自动取敏感度分析中影响最大的不利扰动。若资产在预期寿命前耗尽，改为明确告警：

```text
• 警告：资产将在 78.3 岁耗尽，比预期寿命早 6.7 岁
```

### 6.3 逐年明细表

```text
=== 逐年明细 ===
 年龄    年末资产(万)   当年储蓄(万)   当年支取(万)   当年收益(万)   阶段
  31        30.2           9.0            0.0            1.2       积累
  32        40.8           9.0            0.0            1.7       积累
 ...
  40       147.0           9.0            0.0            6.6       积累
  41       163.4           9.0            0.0            7.3       达成
  42       165.3           0.0            6.0            7.9       退休
 ...
  85       443.8           0.0            6.0           20.8       退休
```

「阶段」列区分积累期（积累）、跨越门槛那一年（达成）与退休期（退休）。表格到预期寿命为止；若资产提前耗尽，则到耗尽那一年为止。

### 6.4 折线图（matplotlib）

- 横轴：年龄（当前年龄 → 预期寿命）
- 纵轴：资产（万元，今天购买力）
- 主曲线：基准情形的完整生命周期（积累期上升 → 退休期下降或继续上升）
- 辅助曲线：情景收益率下的积累期轨迹
- 参考线：财富自由门槛 T（水平虚线）、财富自由年龄（垂直虚线）
- 输出：保存 PNG 到脚本同目录并打印路径，随后弹窗显示

`--no-chart` 时跳过整个绘图步骤。图形环境不可用时只保存 PNG 并提示。

## 7. 边界与错误处理

沿用第 1 版全部规则（实际收益率 ≤ 0 且储蓄不足以抵消购买力缩水时报错、`r_m == 0` 退化、已达标返回 0、负数参数拦截、闭式解与逐月迭代交叉校验）。

新增：

| 情形 | 处理 |
|---|---|
| 年支出 > 年收入 | 报错「入不敷出，年储蓄为负，无法积累」 |
| 预期寿命 ≤ 当前年龄 | 报错「预期寿命必须大于当前年龄」 |
| 达到自由的年龄 > 预期寿命 | 不报错，结论中标注「在预期寿命内无法达成」 |
| 当前资产 ≥ 自由门槛 | 达成年龄 = 当前年龄，消耗期直接从当前开始推演 |
| 绘图失败（无 matplotlib / 无图形环境） | 打印提示，其余结果照常输出，不影响退出码 |

## 8. 窗口停留

双击 `.py` 时 Windows 为 `python.exe` 单独新建控制台，`GetConsoleProcessList` 返回的进程数为 1；从 cmd / PowerShell 启动时宿主进程也在同一控制台，返回数 ≥ 2。据此区分双击与命令行。

`run_cli()` 用 `try / except SystemExit / except Exception / finally` 包裹 `main()`，保证成功、参数错误（exit 2）、未预期异常（打印 traceback，exit 1）三条路径都会走到 `pause_before_exit()`。`--no-pause` 可强制关闭。
